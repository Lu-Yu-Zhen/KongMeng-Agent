# 学生学情分析技能

## 一、适用场景

本技能适用于以下教学场景的学情分析需求：

| 场景类型 | 适用情境 | 分析重点 |
|---------|---------|---------|
| 单次考试后学情分析 | 某次月考、期中、期末考试结束后 | 成绩分布、知识点掌握、能力短板定位 |
| 阶段性学情分析 | 一个教学阶段（如一个月、半个学期）结束 | 学习进展趋势、阶段目标达成度 |
| 个体学生学情诊断 | 针对某位学生的深度诊断 | 该生知识盲区、能力短板、提升路径 |
| 班级整体学情分析 | 以班级为单位的整体评估 | 班级整体水平、分层结构、共性问题 |
| 学科薄弱点诊断 | 针对某一学科或知识模块的诊断 | 薄弱知识点定位、能力层级短板、题型失分分析 |

## 二、学情分析标准流程

### 第一步：确认分析对象与范围

- **确认分析对象**：个体学生 / 班级 / 年级
- **确认数据来源**：单次考试成绩 / 多次成绩对比 / 作业表现 / 综合评估
- **确认学科范围**：单科 / 多科 / 全科
- **确认分析深度**：概览级（成绩统计） / 标准级（知识+能力） / 深度级（全维度+趋势+分层）
- **确认输出格式**：Markdown 报告 / HTML 可视化报告 / 简要摘要

### 第二步：数据采集与整理

- **成绩数据**：各题得分、总分、满分、排名等
- **知识点标注**：每道题对应的知识点编码与名称
- **能力层级标注**：每道题对应的能力层级（识记/理解/应用/分析/综合/评价）
- **题型标注**：每道题的题型分类（选择题/填空题/解答题等）
- **历史数据**：历次考试成绩（用于趋势分析）
- **数据清洗**：缺失值处理、异常值识别、数据标准化

### 第三步：多维度分析

按以下六大维度展开分析：

1. **成绩维度** — 分数分布、平均分、及格率、优秀率、标准差等统计指标
2. **知识维度** — 知识点掌握率、薄弱知识点定位、知识盲区图谱构建
3. **能力维度** — 布鲁姆六层能力分析（识记/理解/应用/分析/综合/评价）
4. **题型维度** — 各题型得分率、题型优劣势分析
5. **趋势维度** — 历次成绩对比、进退步判定、稳定性分析
6. **个体维度** — 分层分类（优秀生/中等生/学困生）特征画像

### 第四步：生成诊断报告

按照标准报告结构生成学情诊断报告，结构如下：

> 基本信息 → 成绩概览 → 知识掌握分析 → 能力水平分析 → 题型分析 → 薄弱点诊断 → 分层学生分析 → 教学建议 → 附录

详细模板见 `assets/学情分析报告模板.md`（Markdown版）和 `assets/学情分析报告模板.html`（HTML可视化版）。

### 第五步：教学建议输出

依据诊断结果，遵循以下原则生成针对性教学建议：

- **针对性**：基于具体数据，指向具体薄弱点
- **可操作性**：建议明确具体，可落地执行
- **分层性**：区分优秀生/中等生/学困生不同策略
- **发展性**：不仅补救短板，更要促进持续发展

详细生成指南见 `references/教学建议生成指南.md`。

## 三、分析维度体系

### 3.1 成绩维度

| 指标 | 计算方法 | 含义 |
|------|---------|------|
| 分数分布 | 各分数段人数/占比 | 反映整体成绩分布形态 |
| 平均分 | 总分 / 人数 | 反映整体平均水平 |
| 及格率 | 及格人数 / 总人数 × 100% | 反映达标情况 |
| 优秀率 | 优秀人数 / 总人数 × 100% | 反映拔尖水平 |
| 标准差 | sqrt(Σ(xi-μ)²/n) | 反映成绩离散程度 |
| 得分率 | 实际得分 / 满分 × 100% | 反映掌握程度 |
| 中位数 | 排序后中间值 | 反映典型水平（抗极端值） |

### 3.2 知识维度

- **知识点掌握率**：按知识点分类统计该知识点相关题目的平均得分率
- **薄弱知识点定位**：掌握率低于 60% 的知识点判定为薄弱
- **知识盲区图谱**：掌握率低于 40% 的知识点标记为知识盲区
- **掌握率分级标准**：
  - 优秀（≥85%）：知识点掌握扎实
  - 良好（70%-84%）：基本掌握，可进一步提升
  - 一般（60%-69%）：掌握不牢固，需巩固
  - 薄弱（40%-59%）：掌握不足，需重点补救
  - 盲区（<40%）：严重欠缺，需系统重学

### 3.3 能力维度（布鲁姆六层能力模型）

| 能力层级 | 定义 | 典型题型特征 |
|---------|------|------------|
| 识记 | 记忆事实、术语、方法 | 直接回忆、填空、判断 |
| 理解 | 把握材料意义、解释归纳 | 解释说明、改写、举例 |
| 应用 | 在新情境中使用知识 | 常规计算、套用公式 |
| 分析 | 分解结构、辨别关系 | 比较分析、分解论证 |
| 综合 | 整合信息、形成新整体 | 开放性论述、设计方案 |
| 评价 | 基于标准做出判断 | 评判论证、评价方案 |

### 3.4 题型维度

- **选择题**：考查基础知识与辨别能力
- **填空题**：考查精确记忆与简洁表达
- **解答题**：考查综合应用与逻辑推理
- **实验探究题**：考查科学探究与实践能力
- **作文/论述题**：考查综合表达与思辨能力
- **各题型得分率分析**：识别题型优劣势，指导训练重点

### 3.5 趋势维度

- **历次成绩对比**：至少2次成绩数据，计算变化幅度与方向
- **进退步判定标准**：
  - 显著进步：排名上升≥5名 或 得分率提升≥10%
  - 稳中有进：排名上升1-4名 或 得分率提升5%-9%
  - 保持稳定：排名变化≤2名 且 得分率变化在±5%以内
  - 略有退步：排名下降1-4名 或 得分率下降5%-9%
  - 显著退步：排名下降≥5名 或 得分率下降≥10%
- **稳定性分析**：通过多次成绩的标准差衡量稳定性

### 3.6 个体维度（分层分类标准）

| 层次 | 划分标准（参考） | 特征分析重点 |
|------|----------------|------------|
| 优秀生 | 排名前20% 或 得分率≥85% | 能力短板、拔高方向、竞赛潜力 |
| 中等生 | 排名20%-80% 或 得分率60%-84% | 知识漏洞、方法改进、突破瓶颈 |
| 学困生 | 排名后20% 或 得分率<60% | 基础薄弱、学习态度、补救方案 |

## 五、教学建议生成原则

### 5.1 针对性原则

教学建议必须基于具体诊断数据，指向明确的薄弱点，避免笼统空泛。

- **示例**：不说"加强基础知识学习"，而说"针对'一元二次方程求根公式'知识点（掌握率42%），建议安排2课时专项复习，配合10道针对性练习"

### 5.2 可操作性原则

建议应具体到可执行的程度，包含操作步骤、资源建议、时间安排。

- **示例**：不说"多做练习"，而说"每周完成3组'函数图像应用'专项训练，每组5题，限时20分钟，完成后对照解析订正"

### 5.3 分层性原则

根据学生层次差异，提供分层教学策略与目标。

- **优秀生**：拓展提升、竞赛训练、自主探究
- **中等生**：查漏补缺、方法优化、突破瓶颈
- **学困生**：夯实基础、降低难度、情感激励

### 5.4 发展性原则

建议不仅关注当前问题补救，更要着眼长远发展，培养元认知能力与自主学习能力。

- **示例**："在补救知识薄弱点的同时，引导学生建立错题反思习惯，每周进行一次错题回顾与归纳总结"

## 六、使用说明

### 调用前需向用户确认以下信息

在执行学情分析前，请向用户确认以下关键参数：

1. **分析对象**：个体学生 / 班级 / 年级？（影响分析范围与分层方式）
2. **数据来源**：单次考试 / 多次考试对比 / 作业数据 / 综合评估？（影响趋势分析可行性）
3. **学科范围**：单科 / 多科 / 全科？（影响维度分析深度）
4. **分析深度**：概览级 / 标准级 / 深度级？（影响报告篇幅与维度覆盖）
5. **输出格式**：Markdown 报告 / HTML 可视化报告 / 简要摘要？（影响呈现方式）

### 数据输入格式建议

**方式一：命令行参数**（适合简单分析）

```
python scripts/analyze_student.py --name "张三" --subject "数学" --exam "期中考试" --data data.json
```

**方式二：JSON 文件**（适合完整分析）

```json
{
  "学生姓名": "张三",
  "班级": "高三(2)班",
  "学科": "数学",
  "考试名称": "2025年秋季期中考试",
  "满分": 150,
  "题目数据": [
    {
      "题号": 1,
      "题型": "选择题",
      "满分": 5,
      "得分": 5,
      "知识点": ["集合的概念"],
      "能力层级": "识记"
    }
  ],
  "历史成绩": [
    {"考试": "月考一", "得分": 105, "排名": 15},
    {"考试": "期中考试", "得分": 118, "排名": 8}
  ]
}
```
