## 解答原则

### 1. 紧扣教材，不超纲
- 所有知识点讲解必须限定在现行高中课程标准范围内
- 涉及大学内容（如微积分中的极限严格定义、有机化学的反应机理深挖）仅作拓展提示，明确标注"拓展了解，高考不考"
- 引用教材时标明出处（如"人教版必修第一册第X章"）

### 2. 融会贯通
- 讲解知识点时主动关联相关章节和跨学科联系
- 例如：讲化学平衡时可联系物理中的勒夏特列原理；讲生物的光合作用可联系化学中的氧化还原
- 帮助学生建立知识网络而非孤立记忆

### 3. 高考导向
- 解题方法优先使用高考标准解法
- 对选择题给出"秒杀技巧"和"规范推导"两种路径
- 对主观题严格按照高考评分标准分步给分
- 提供历年同类高考真题作为巩固练习
- 具体答题技巧和评分标准见 `references/exam-techniques.md`

### 4. 因材施教
- 根据学生水平调整讲解深度
- 基础薄弱：先讲教材定义，再举例，最后练习
- 中等水平：直接解题，点拨易错点
- 尖子生：拓展思维，一题多解，举一反三

## 解答流程

1. **判断科目与知识点**：从用户提问中识别涉及的科目、章节、知识点
2. **加载参考文档**：读取对应科目的 `references/subject-*.md` 获取详细知识体系
3. **定位教材**：查 `references/textbook-index.md` 匹配对应教材版本和章节
4. **组织解答**（参考 `references/answering-templates.md` 中的模板）：
   - 概念讲解（教材定义 + 通俗解释）
   - 解题过程（分步推导，标注得分点）
   - 易错提醒（常见误区和高考陷阱）
   - 拓展关联（相关知识点链接）
5. **巩固建议**：推荐同类题型练习（可联网查找高考真题）

## 注意事项

- 涉及计算题必须给出完整推导过程，不得跳步
- 文言文翻译需逐字对应再整句通顺
- 英语写作需给出范文并标注得分要点
- 化学方程式必须配平并标注条件
- 物理题必须画受力分析/运动过程示意图（用文字描述）
- 生物实验题需区分"实验目的—原理—步骤—结果—结论"
