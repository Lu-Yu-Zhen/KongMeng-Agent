# 英语知识体系与高考题型

## 知识模块详解

### 一、听力
**教材出处**：人教版必修第一至三册、选择性必修第一至四册

- **短对话**（5题，每题1.5分）：
  - 场景判断（购物/问路/就餐/看病/天气等）
  - 数字与时间计算
  - 人物关系推断
- **长对话**（10题，每题1.5分）：
  - 主旨大意
  - 细节信息获取
  - 态度与意图推断
- **独白**（5题，每题1.5分）：
  - 广播/通知/演讲
  - 信息记录与匹配

**易错点**：
- 同音词混淆（如flour/flower）
- 干扰信息（先说一个再更正）
- 英美数字表达差异（billion/million）

### 二、阅读理解
**教材出处**：贯穿各册

- **主旨大意题**：找topic sentence，注意首尾段
- **细节理解题**：定位原文，同义替换识别
- **推理判断题**：基于文本合理推断，不主观臆断
- **词义猜测题**：上下文语境、构词法
- **作者态度题**：识别褒义/贬义/中性词

**高考题型**：15题，每题2.5分，共37.5分（新高考）

**易错点**：
- 过度推断（超出文本范围）
- 混淆fact与opinion

### 三、七选五
**教材出处**：贯穿各册

- **设空位置**：段首/段中/段尾
- **解题策略**：
  - 词汇衔接：代词指代、同义词复现
  - 逻辑衔接：因果/转折/并列/递进
  - 结构衔接：总分/分总/并列结构

**高考题型**：5题，每题2.5分，共12.5分

### 四、完形填空
**教材出处**：贯穿各册

- **语境推断**：上下文逻辑关系
- **词义辨析**：近义词/形近词区分
- **固定搭配**：动词短语/介词搭配
- **情感线索**：文章情感脉络追踪

**高考题型**：15题，每题1分，共15分（新高考）

**易错点**：
- 只看空格所在句子，忽略全文语境
- 忽略情感线索的连贯性

### 五、语法填空
**教材出处**：贯穿各册

- **有提示词**：
  - 动词：时态/语态/非谓语动词（to do/doing/done）
  - 名词：单复数
  - 形容词/副词：比较级/最高级/词性转换
  - 代词：人称代词/反身代词
- **无提示词**：
  - 介词（in/on/at/with/by等）
  - 连词（and/but/or/so/because等）
  - 冠词（a/an/the）
  - 关系词（who/which/that/where/when）

**高考题型**：10题，每题1.5分，共15分

**易错点**：
- 非谓语动词的三种形式选择
- 定语从句与同位语从句的区分

### 六、应用文写作
**教材出处**：人教版必修各册应用文单元

- **书信类**：建议信/感谢信/邀请信/申请信/道歉信
- **格式要求**：称呼/正文/落款
- **语言要求**：
  - 要点齐全（覆盖所有内容要点）
  - 语言准确（语法正确，用词得当）
  - 层次清晰（适当使用连接词）
  - 有高级表达（倒装/非谓语/从句）

**高考题型**：80词左右，15分

**评分标准**：
- 13-15分：要点全，语言流畅，有高级表达
- 10-12分：要点全，语言基本正确
- 7-9分：漏1-2个要点，有较多语法错误

### 七、读后续写
**教材出处**：人教版选择性必修各册

- **要求**：阅读350词左右的英语文章，续写两段（约150词）
- **核心能力**：
  - 情节合理续写（与前文逻辑一致）
  - 情感描写（动作描写/心理描写/环境描写）
  - 语言丰富（多样句式+生动词汇）
  - 主题升华（结尾点题）

**高考题型**：150词左右，25分

**评分标准**：
- 21-25分：与原文融洽度高，情节合理，语言丰富生动
- 16-20分：与原文融洽度较高，情节较合理，语言较丰富
- 11-15分：基本续写，语言一般

**写作技巧**：
- 动作链：连续使用动词描写动作过程
- 情感词：使用具体情感词（delighted/terrified/relieved等）替代happy/sad
- 环境烘托：用天气/景物烘托人物心情
- 首尾呼应：结尾呼应开头主题

## 融会贯通提示

- 语法填空与完形填空互为补充（语篇理解能力）
- 阅读理解的同义替换技巧可用于写作中的paraphrase
- 课文中的好词好句可直接用于写作素材积累
- 读后续写的描写技巧可从课文中的文学性语篇学习
