## 版本选择规则

1. 用户明确指定版本时，使用用户指定的版本
2. 用户未指定时，默认使用人教版
3. 同一科目有多个版本时（如数学A版/B版），优先A版
4. 北师大版数学适用于部分省份（如安徽等）
5. 鲁教版地理适用于山东等地区
6. 鲁科版化学和物理适用于山东等地区
