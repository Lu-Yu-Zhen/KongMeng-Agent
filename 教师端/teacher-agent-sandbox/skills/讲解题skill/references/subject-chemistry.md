# 化学知识体系与高考题型

## 知识模块详解

### 一、化学基础
**教材出处**：人教版必修第一册

- **物质的量**：
  - 摩尔（mol）：1mol含阿伏伽德罗常数（Nₐ≈6.02×10²³）个微粒
  - 摩尔质量M（g/mol）：数值等于相对分子质量
  - 气体摩尔体积：标准状况下Vₘ=22.4L/mol
  - 物质的量浓度：c=n/V
- **化学用语**：
  - 化学式/电子式/结构式/结构简式
  - 原子结构示意图/电子排布式
- **离子方程式**：
  - 写→拆→删→查四步法
  - 强酸/强碱/可溶性盐拆写离子，其余写化学式
- **氧化还原反应**：
  - 氧化剂（得电子，被还原）→还原产物
  - 还原剂（失电子，被氧化）→氧化产物
  - 电子转移数目计算
  - 双线桥法/单线桥法表示

**高考题型**：选择题（阿伏伽德罗常数/离子方程式/氧化还原判断）

**易错点**：
- Nₐ题中忽略隐含条件（如可逆反应、浓度限制）
- 离子方程式中弱电解质未写化学式

### 二、实验基础
**教材出处**：人教版必修第一册

- **常见仪器**：试管/烧杯/容量瓶/滴定管/蒸馏烧瓶/冷凝管
- **基本操作**：
  - 过滤：分离固体和液体
  - 蒸发结晶：分离可溶性固体
  - 蒸馏：利用沸点差分离互溶液体
  - 萃取分液：利用溶解度差分离
  - 配制一定物质的量浓度溶液
- **实验安全**：防倒吸/防暴沸/防中毒/防火

**高考题型**：选择题+实验大题

### 三、物质结构
**教材出处**：人教版必修第一册、选择性必修第二册

- **原子结构**：
  - 能层（K/L/M/N）与能级（s/p/d/f）
  - 构造原理/泡利不相容原理/洪特规则
  - 电子排布式与电子排布图
- **元素周期律与周期表**：
  - 周期（横行）/族（纵列）
  - 同周期从左到右：原子半径减小，金属性减弱，非金属性增强
  - 同主族从上到下：原子半径增大，金属性增强，非金属性减弱
- **化学键**：
  - 离子键（金属+非金属）、共价键（非金属+非金属）、金属键
  - σ键（头碰头）与π键（肩并肩）
  - 键参数：键长/键能/键角
  - 杂化轨道理论：sp/sp²/sp³
  - VSEPR模型预测分子构型

**高考题型**：选择题+物质结构大题（选考，15分）

### 四、反应原理
**教材出处**：人教版选择性必修第一册

#### 化学反应速率
- 速率表示：v=Δc/Δt
- 影响因素：浓度/温度/催化剂/表面积
- 速率常数k

#### 化学平衡
- 平衡特征：等（正逆速率相等）、动（动态平衡）、定（各组分浓度不变）、变（条件改变平衡移动）
- 平衡常数K：只与温度有关
- 勒夏特列原理：平衡向减弱这种改变的方向移动
- 转化率α计算

#### 电解质溶液
- 弱电解质电离平衡：电离常数Ka
- 水的离子积：Kw=c(H⁺)·c(OH⁻)=10⁻¹⁴（25°C）
- pH计算：pH=-lgc(H⁺)
- 盐类水解：强酸弱碱盐水解显酸性，强碱弱酸盐水解显碱性
- 缓冲溶液

#### 电化学
- 原电池：化学能→电能
  - 负极（氧化反应）/正极（还原反应）
  - 盐桥作用：维持电荷平衡
- 电解池：电能→化学能
  - 阳极（氧化反应）/阴极（还原反应）
  - 放电顺序
- 金属腐蚀与防护

**高考题型**：反应原理大题（必考，15分）+选择题

**易错点**：
- 平衡常数表达式书写时纯固体/纯液体不写入
- 电化学中正负极/阴阳极的氧化还原反应类型混淆

### 五、元素化合物
**教材出处**：人教版必修第一册、必修第二册

#### 金属及其化合物
- **钠**：Na→Na₂O→Na₂O₂→NaOH→Na₂CO₃/NaHCO₃
  - Na₂O₂与水/CO₂反应（既是氧化剂又是还原剂）
  - Na₂CO₃与NaHCO₃的转化与鉴别
- **铝**：Al→Al₂O₃→Al(OH)₃→Al³⁺/AlO₂⁻
  - 两性：Al(OH)₃既溶于酸又溶于碱
- **铁**：Fe→Fe₂O₃/Fe₃O₄→Fe²⁺/Fe³⁺
  - Fe²⁺与Fe³⁺的鉴别（KSCN法）
  - Fe²⁺↔Fe³⁺转化

#### 非金属及其化合物
- **氯**：Cl₂→HCl→HClO→ClO⁻
  - 氯水成分（Cl₂/HClO/H⁺/Cl⁻等）
  - 漂白粉有效成分Ca(ClO)₂
- **硫**：S→SO₂→SO₃→H₂SO₄
  - 浓硫酸特性：吸水性/脱水性/强氧化性
- **氮**：N₂→NH₃→NO→NO₂→HNO₃
  - 喷泉实验原理
  - 硝酸强氧化性（浓/稀产物不同）

**高考题型**：无机推断题/工艺流程题

### 六、有机化学
**教材出处**：人教版选择性必修第三册

- **官能团**：
  | 官能团 | 结构 | 特征反应 |
  |--------|------|---------|
  | 烯键 | C=C | 加成/氧化/加聚 |
  | 炔键 | C≡C | 加成/氧化 |
  | 卤素 | -X | 取代（水解/消去） |
  | 羟基 | -OH | 取代/消去/酯化/氧化 |
  | 醛基 | -CHO | 加成（还原）/氧化 |
  | 羧基 | -COOH | 酯化/中和 |
  | 酯基 | -COO- | 水解 |
- **反应类型**：
  - 取代反应：卤代/硝化/酯化/水解
  - 加成反应：加氢/加卤素/加H₂O/加HX
  - 消去反应：醇脱水/卤代烃脱HX
  - 氧化反应：醇→醛→羧酸
  - 缩聚/加聚反应
- **同分异构体**：
  - 碳链异构/位置异构/官能团异构
  - 书写顺序：碳链→位置→官能团

**高考题型**：有机推断题（选考，15分）+选择题

**易错点**：
- 酯化反应是可逆反应（需标可逆号）
- 醛基银镜反应注意条件（水浴加热）
- 同分异构体书写遗漏

### 七、化学与生活/技术
**教材出处**：人教版必修第二册

- **材料**：金属材料/硅酸盐材料/高分子材料/复合材料
- **能源**：化石能源/新能源
- **环境**：酸雨/光化学烟雾/水体富营养化/白色污染
- **化工情境**：海水资源综合利用/矿物冶炼

**高考题型**：选择题+工艺流程题情境

## 融会贯通提示

- 物质结构与元素化合物：结构决定性质（如Na₂O₂中O的-1价决定其既氧化又还原）
- 反应原理与元素化合物：用平衡移动原理解释元素化合物的转化条件
- 有机化学与反应原理：有机反应也是化学平衡，可分析转化率
- 电化学与氧化还原：原电池/电解池本质是氧化还原反应的电子转移
