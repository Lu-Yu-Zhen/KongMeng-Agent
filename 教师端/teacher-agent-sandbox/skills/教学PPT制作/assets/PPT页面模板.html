牛顿第二定律

定律内容

  • 内容：物体的加速度与所受合外力成正比，与物体的质量成反比
  • 公式：F = ma，其中 F 为合外力，m 为质量，a 为加速度
  • 方向性：加速度的方向与合外力的方向始终相同
  • 单位：力的单位为牛顿（N），1N = 1 kg·m/s²

模板4：例题展示页

典型例题

例题

质量为 2kg 的物体放在光滑水平面上，受到水平方向的恒力 F = 6N 作用。 求物体的加速度大小和 3 秒末的速度大小。

解题过程
1
受力分析：物体受重力 G、支持力 N 和拉力 F，合力即拉力 F = 6N
2
求加速度：由牛顿第二定律 F = ma 得，a = F/m = 6/2 = 3 m/s²
3
求末速度：v = v₀ + at = 0 + 3×3 = 9 m/s

模板5：课堂练习页

课堂练习

思考时间：30秒
第1题

关于牛顿第二定律，下列说法正确的是：

A
加速度与合外力成正比
B
加速度方向与合外力方向相同
C
加速度与物体的速度成正比
D
合外力为零时加速度不一定为零
正确答案：B　牛顿第二定律指出，加速度的方向与合外力的方向始终相同。 选项A缺少"质量不变"的前提；选项C混淆了加速度与速度的概念；选项D错误，合外力为零时加速度必为零。
