# 教学PPT制作

本技能用于帮助教师制作高质量的教学演示文稿（PPT），涵盖内容规划、版面设计、视觉呈现与互动设计，适用于中小学及高校各学科课堂使用。

## 适用场景

- 新授课课件制作
- 复习课/期末复习课件
- 公开课/示范课课件
- 微课课件
- 说课课件

## 制作标准流程

### 第一步：需求确认

制作前需向用户确认以下信息：

1. **学科与年级**（如：高中物理，必修一）
2. **课题名称**（如：牛顿第二定律）
3. **课件类型**（新授课/复习课/公开课/微课/说课）
4. **页数要求**（如：15-20页）
5. **风格偏好**（简约风/学术风/活泼风/国风等）
6. **特殊需求**（如：需要动画演示、嵌入视频、互动练习等）

### 第二步：内容架构设计

**标准课件结构（以新授课为例）：**

| 页码 | 页面内容 | 说明 |
|------|---------|------|
| P1 | 封面 | 课题、学科、年级、教师姓名 |
| P2 | 学习目标 | 3-5条，用图标/编号清晰呈现 |
| P3 | 情境导入 | 图片/视频/问题/故事引入 |
| P4-P8 | 新知讲解 | 每页一个核心知识点，图文结合 |
| P9-P10 | 典型例题 | 题目+解析，分步展示 |
| P11-P12 | 课堂练习 | 基础+提高，可设计互动选择 |
| P13 | 知识小结 | 思维导图/知识结构图 |
| P14 | 拓展延伸 | 联系实际/学科前沿 |
| P15 | 作业布置 | 分层作业 |
| P16 | 结尾页 | 感谢/下节课预告 |

### 第三步：版面设计规范

**1. 尺寸与比例**
- 标准比例：16:9（宽屏）
- 页面尺寸：1280×720 或 1920×1080

**2. 字体规范**
- 标题字体：思源黑体 / 微软雅黑（加粗），字号 36-44pt
- 正文字体：思源宋体 / 微软雅黑，字号 24-28pt
- 标注/备注：20-22pt
- 强调内容：加粗或使用主色，不使用过多颜色

**3. 配色方案**
- 主色：1种（体现学科特色，如理科蓝、文科暖色）
- 辅色：1-2种（用于强调与区分）
- 背景：浅色为主（白色/浅灰/浅色渐变）
- 文字与背景对比度 ≥ 4.5:1

**4. 排版原则**
- 每页文字不超过6行，每行不超过20字
- 图文比例 ≥ 1:1（适当时图多于文）
- 留白率 ≥ 30%
- 对齐统一：左对齐或居中对齐，全课件一致
- 动画克制：仅用于逻辑呈现（如逐步展示解题步骤）

### 第四步：视觉元素设计

**1. 图表使用**
- 数据对比 → 柱状图/条形图
- 趋势变化 → 折线图
- 比例关系 → 饼图
- 结构关系 → 思维导图/流程图
- 实验装置 → 手绘示意图或实物照片

**2. 图片规范**
- 使用高清图片（分辨率 ≥ 1920×1080）
- 图片风格统一（同课件内不混用照片与矢量图）
- 图片需有简短说明文字
- 涉及人物图片注意版权

**3. 图标与符号**
- 使用统一风格的图标集
- 学科符号规范使用（如数学公式用公式编辑器）
- 流程图箭头方向统一

### 第五步：互动设计

**1. 课堂提问设计**
- 选择题：用A/B/C/D选项卡片呈现
- 填空题：答案用动画延迟显示
- 讨论题：设置思考时间提示（如"思考30秒"）

**2. 练习互动**
- 即时反馈：正确答案高亮显示
- 错误提示：常见错误选项标注易错原因
- 分层练习：基础→提高→挑战，逐步进阶

**3. 多媒体嵌入**
- 视频片段：控制在2-3分钟内，嵌入页面非跳转
- 音频：背景音乐轻柔不干扰教学
- 动画演示：用于抽象概念具象化（如分子运动、几何变换）

## 各学科特色设计指南

| 学科 | 设计要点 | 推荐视觉元素 |
|------|---------|-------------|
| 语文 | 课文朗读配图、意境渲染 | 古风插图、水墨背景 |
| 数学 | 几何动态演示、解题步骤分解 | 动态几何图形、函数图像 |
| 英语 | 情境对话、词汇图片匹配 | 实物图片、对话气泡 |
| 物理 | 实验模拟、物理过程动画 | 实验装置图、受力分析图 |
| 化学 | 分子结构3D模型、反应过程 | 化学方程式、实验视频 |
| 生物 | 生命过程图解、显微图像 | 生物结构图、生态照片 |
| 历史 | 时间轴、历史地图、史料图片 | 朝代时间轴、历史人物画像 |
| 地理 | 地图叠加、地理现象模拟 | 地形图、气候数据图 |

## 质量检查清单

完成课件后，逐项检查：

- [ ] 封面信息完整（课题、学科、教师）
- [ ] 学习目标明确可读
- [ ] 每页文字量适中（不超过6行）
- [ ] 图文搭配合理
- [ ] 配色统一协调
- [ ] 字体大小符合规范
- [ ] 动画使用克制得当
- [ ] 例题解析步骤清晰
- [ ] 课堂练习有互动设计
- [ ] 知识小结完整
- [ ] 作业布置分层
- [ ] 总页数与课时匹配（1课时15-20页）

## 使用说明

当调用此技能时，按上述流程操作：
1. 先与用户确认需求信息（学科、课题、类型、风格等）
2. 设计内容架构与页面分配
3. 规划版面设计与视觉风格
4. 生成完整的课件内容方案（含每页的文字内容、图片建议、动画说明）
5. 如需生成实际PPT文件，可结合pptx技能或html-deck技能输出

最终输出的课件应达到"拿到即可上课"的完成度。
