# 教案编写

本技能用于帮助教师编写结构完整、内容详实、格式规范的教案，适用于中小学各学科及高校课程。

## 适用场景

- 编写新授课教案
- 编写复习课教案
- 编写实验课/实践课教案
- 编写习题课/讲评课教案
- 按指定教材章节或知识点编写教案

## 教案标准结构

一份完整的教案应包含以下模块，缺一不可：

### 一、基本信息

```
课题名称：__________
学科：__________    年级：__________
课时：__________    课型：__________（新授课/复习课/实验课/习题课）
教材版本：__________
编写日期：__________
```

### 二、教材分析

- 本节课在教材中的地位与作用
- 知识的前后联系（承接什么、为后续什么知识铺垫）
- 教材内容的核心要点提炼

### 三、学情分析

- 学生已有知识基础
- 学生认知特点与思维水平
- 可能存在的学习障碍与困难点
- 学生学习兴趣与动机分析

### 四、教学目标

按新课标三维目标或核心素养四维度编写，需具体、可测量、可达成：

**知识与技能目标：**
- 使用"能说出…""能理解…""能运用…解决…"等行为动词
- 每条目标对应一个具体知识点或技能

**过程与方法目标：**
- 描述学生经历的学习过程
- 体现科学探究/合作学习/自主学习等方法

**情感态度与价值观目标：**
- 结合学科特点融入德育/美育/科学精神
- 避免空洞说教，与具体教学内容挂钩

### 五、教学重难点

- **教学重点：** 本节课最核心、最基础的知识或技能（1-3个）
- **教学难点：** 学生最易混淆、最难理解的内容（1-2个）
- 每个难点需附简要的突破策略说明

### 六、教学准备

- 教师准备：教具、课件、实验器材、教学视频等
- 学生准备：预习内容、学具、资料收集等

### 七、教学过程

这是教案的核心部分，需按环节详细展开。每个环节包含以下要素：

| 环节 | 教师活动 | 学生活动 | 设计意图 | 时间 |
|------|---------|---------|---------|------|

**标准环节流程：**

1. **导入新课（3-5分钟）**
   - 情境创设方式：生活实例/故事/实验演示/问题驱动/复习导入
   - 激发学生兴趣，引出课题

2. **新知探究（15-20分钟）**
   - 分层次呈现新知识，遵循由易到难、由具体到抽象
   - 每个知识点：教师引导 → 学生活动 → 归纳总结
   - 关键问题设计需有启发性

3. **巩固练习（8-12分钟）**
   - 基础题：面向全体，巩固基本概念
   - 提高题：分层设计，拓展思维
   - 及时反馈与纠错

4. **课堂小结（3-5分钟）**
   - 师生共同梳理知识脉络
  - 可用思维导图/表格/口诀等形式

5. **布置作业（1-2分钟）**
   - 基础作业 + 拓展作业分层布置
   - 可选实践性/探究性作业

### 八、板书设计

- 展示板书的结构与布局
- 体现知识的逻辑关系
- 主板书 + 副板书分区设计
- 可用文字描述或简图示意

### 九、教学反思（课后填写）

- 教学目标达成情况
- 教学过程中的亮点与不足
- 改进措施与后续调整方向

## 编写规范

1. **语言风格：** 使用规范的教师教学用语，简洁明了，避免口语化
2. **时间分配：** 各环节时间总和需等于课时总时长（通常40或45分钟）
3. **问题设计：** 每个教学环节至少设计1-2个有质量的关键问题
4. **活动设计：** 体现以学生为主体，学生活动时间不少于总课时的1/3
5. **差异化教学：** 在练习和提问环节体现分层设计
6. **格式统一：** 表格对齐，编号规范，层次清晰

## 使用说明

当调用此技能时，请向用户确认以下信息：

1. **学科与年级**（如：高一数学）
2. **课题名称**（如：三角函数）
3. **课型**（新授课/复习课/专题课/习题课）
4. **课时长度**（默认45分钟）
5. **教材版本**（如：人教版/北师大版）
6. **特殊要求**（如：需要融入思政元素、注重实验探究等）

根据以上信息，按照上述标准结构生成完整教案，确保每个模块内容充实、逻辑清晰、可直接用于教学实践。
