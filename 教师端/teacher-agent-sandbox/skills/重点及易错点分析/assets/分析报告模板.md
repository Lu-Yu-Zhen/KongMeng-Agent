## 使用说明

本模板为「重点及易错点分析」技能的标准报告模板，包含七大模块。请按照各模块的填写说明逐项完成，以 `{ }` 标注的内容为需替换的占位符，以 `（ ）` 标注的内容为填写提示。完成填写后请删除所有使用说明和提示文字。

**七大模块一览：**

| 模块 | 名称 | 核心内容 |
|------|------|---------|
| 一 | 分析概述 | 基本信息、分析目的与适用场景 |
| 二 | 知识结构 | 知识体系概览与逻辑关系 |
| 三 | 重点知识分析 | 3-8个重点知识的详细分析 |
| 四 | 易错点分析 | 5-15个易错点（含六要素） |
| 五 | 错因分类汇总 | 按错因类型分类统计与防范策略 |
| 六 | 教学建议 | 教学优先级、策略与复习建议 |
| 七 | 附录 | 练习题清单、考前注意事项等 |
