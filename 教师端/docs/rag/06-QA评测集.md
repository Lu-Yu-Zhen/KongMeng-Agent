# 06 QA 评测集与评测流程

## 评测集构成

`tests/rag/qa/{学科}.json`，九科共 **450 条**（每科 50 条），覆盖：

- **正例**（每科约 45 条）：问题 → 期望命中的 `expected_kp`（知识点编码）+ `expected_source`（来源），覆盖各模块/章/节/题型，含基础题与跨点综合题。
- **负例**（每科约 5 条）：`negative: true` + 空 `expected_kp`，为跨学科干扰问题（如把英语时态、数学集合、物理公式、化学周期表、地理经纬度混入语文），用于验证**不误召回**。

条目结构：
```json
{
  "subject": "语文",
  "items": [
    {
      "query": "散文行文思路分析，作者常以什么作为贯穿全文的线索？",
      "subject": "语文",
      "expected_kp": "YW-M1C1S1-KP1",
      "expected_source": "人教版统编版必修上册",
      "difficulty": 3,
      "negative": false
    }
  ]
}
```

## 评测指标（`scripts/evaluate.py`）

对每条正例跑 `hybrid.search(query, top_n=top_k)`，统计：

- **Recall@k**：`expected_kp` 出现在 top-k 命中的比例。
- **MRR@k**：`expected_kp` 首次出现的排位倒数均值（未命中记 0）。
- **负例误召回率**：负例问题中 `expected_kp`（应无）被命中的比例。

## 达标门槛

| 指标 | 门槛 |
|---|---|
| Recall@5 | ≥ 0.80 |
| MRR@5 | ≥ 0.75 |
| 负例误召回 | ≤ 0.10 |

## 用法

```bat
:: 全科评测（top-k=5，写报告）
python scripts\evaluate.py
:: 单科评测
python scripts\evaluate.py --subject 数学
:: 指定 top-k 与报告路径
python scripts\evaluate.py --top-k 8 --report docs\rag\eval-report.md
```

## 回归基线

评测脚本每次生成 `eval-report.md`。建议在每次增量构建/改检索逻辑后重跑，比较 Recall / MRR / 负例误召回三项，防止回归。
