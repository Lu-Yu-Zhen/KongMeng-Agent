# 02 九科知识树设计

## 目标
覆盖高中三年全部学科、对接新高考全部题型的高中全学科知识树，作为 RAG 分块与检索的骨架。九科共 9 个 JSON 文件，存于 `rag_data/knowledge-tree/{学科}.json`。

## 结构规范（五级）

```
学科(level1)
└── 模块/册次(level2)   —— 如 语文 M1文学阅读与写作|必修上册
    └── 章(level3)      —— 如 C1 现代文阅读
        └── 节(level4)  —— 如 S1 散文阅读
            └── 知识点(level5, 叶子) —— 含正文 text + 元数据
```

`kp_id` 编码规则：`{学科缩写}-M{模块}C{章}S{节}-KP{序}`，如 `YW-M1C1S1-KP1`（语文，模块1章1节1知识点1）。

## 节点字段（对应 `schema.KnowledgeNode`）

| 字段 | 说明 |
|---|---|
| `kp_id` | 全局唯一编码 |
| `name` | 节点名称 |
| `level` | 1~5 层级 |
| `module / chapter / section` | 模块/章/节 |
| `grade` | 年级/册次 |
| `difficulty / importance` | 难度/重要度 1~5 |
| `level_requirement` | 课标层次 了解/理解/掌握/应用 |
| `exam_type` | 关联高考题型 |
| `source` | 来源（教材册次/课标章节） |
| `version` | 课标/考纲版本 |
| `text` | 知识点正文（叶子必填，供分块） |

| 化学 | 基本概念/元素化合物/有机/反应原理/实验 | `化学.json` |
| 生物 | 分子与细胞/遗传/稳态/生态/生物技术 | `生物.json` |

## 校验

`scripts/validate_tree.py` 校验：五级层级齐全、`kp_id` 全局唯一、无孤儿节点、叶子含正文/难度/重要度/课标层次。合格才允许构建索引。
