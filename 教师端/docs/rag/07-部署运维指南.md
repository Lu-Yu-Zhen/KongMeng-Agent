# 07 部署与运维指南

## 一、依赖安装

`backend/requirements.txt` 已含 RAG 检索层依赖：

```
sqlite-vec>=0.1.6
sqlite-vec==0.1.6 ; python_version >= "3.11"
jieba>=0.42.1
rank-bm25>=0.2.2
```

可选（生产语义检索/重排，安装后自动启用，缺失自动回退 mock/禁用）：
```
onnxruntime>=1.17
tokenizers>=0.15
```

安装（若 PyPI 官方源可用，优先官方源避免镜像 403）：
```bat
pip install -r backend\requirements.txt
pip install -i https://pypi.org/simple sqlite-vec
pip install -i https://pypi.org/simple --no-build-isolation jieba rank-bm25
```

## 二、模型准备与分发

### 方式 A：联网导出（推荐在构建机执行）
```bat
python scripts\export_onnx.py --model bge-large-zh-v1.5 --quantize
python scripts\export_onnx.py --model bge-reranker-v2-m3 --quantize
```
产出到 `rag_data/models/{模型名}/`（model.onnx + tokenizer.json + config.json）。

### 方式 B：离线打包分发
```bat
python scripts\package_models.py --version 1.0.0
```
产出 `rag_data/models-pack/rag-models-1.0.0.zip` + `.sha256` + `.json`，随安装包分发，目标机解压到 `rag_data/models/` 即可。

> 目标机无模型时：embedding 自动走 mock（链路可自测）、rerank 禁用，检索仍可用（仅语义区分度下降）。

## 三、构建索引

```bat
:: 校验知识树
python scripts\validate_tree.py
:: 构建全科索引（断点续建）
python scripts\build_index.py
:: 强制全量
python scripts\build_index.py --force
```

运行后核对 `rag_data/index/manifest.json` 的 `total_chunks` 与 `block_counts`。

## 四、启动服务

```bat
cd backend
python server.py
:: 默认 http://127.0.0.1:8767
```

启动日志确认 `RAG 检索层已挂载：/rag/status、/rag/retrieve...`。验证：
```
GET http://127.0.0.1:8767/rag/status     → vector_store.chunks > 0、bm25_chunks > 0
GET http://127.0.0.1:8767/api/kb/retrieve?subject=数学&topic=函数单调性
```

## 五、环境变量（Electron 注入）

| 变量 | 作用 | 默认 |
|---|---|---|
| `RAG_DATA_ROOT` | 数据根目录 | `教师端/rag_data` |
| `RAG_MODEL_DIR` | 模型目录 | `{RAG_DATA_ROOT}/models` |
| `RAG_EMBED_MODEL` | embedding 模型名 | `bge-large-zh-v1.5` |
| `RAG_EMBED_DIM` | 向量维度 | `1024` |
| `RAG_RERANK_ENABLED` | 是否启用重排 | `1` |
| `RAG_SUBJECT_FILTER` | 是否按学科过滤召回 | `1` |
| `RAG_EMBED_MOCK` | 强制 mock embedding | 自动（无模型时 1） |

## 六、运维要点

1. **降级顺序**：模型缺失→mock embedding + 无重排；索引为空→kb.py 回退旧子串匹配。任一环节故障不导致服务宕机。
2. **增量更新**：新增/修改知识点后重跑 `build_index.py`（断点续建只重算变更块）。
3. **增量语料**：干净文本放入 `rag_data/corpus/{学科}/`，按标注命名后重建。
4. **回归评测**：每次改检索逻辑/增量构建后跑 `scripts/evaluate.py`，对照 `06-QA评测集` 的基线，防止 Recall/MRR 回退。
5. **日志**：`backend/backend.log` 记录检索/构建；`rag_data/logs/` 记录清洗报告；`/rag/status` 提供运行态快照。
6. **安全**：`AGENT_API_TOKEN` 启动时注入可拦截非白名单接口的未授权调用；`CORS_ORIGINS` 收敛为本地来源。

## 七、常见问题

| 现象 | 排查 |
|---|---|
| `/rag/status` 显示 chunks=0 | 未构建索引，运行 `build_index.py` |
| 检索命中差 | 确认非 mock embedding；检查 `manifest.embed_model`；重跑评测 |
| sqlite-vec 安装失败 | 用官方 PyPI 源 `pip install -i https://pypi.org/simple sqlite-vec` |
| 重排不生效 | 确认 `RAG_RERANK_ENABLED=1` 且 `models/bge-reranker-v2-m3/model.onnx` 存在 |
| 服务启动无 /rag 路由 | 看 `backend.log` 中 `RAG 检索层挂载失败` 原因 |
