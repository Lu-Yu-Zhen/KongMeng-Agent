# 03 数据清洗与标注 SOP

## 范围
将原始语料（`rag_data/raw/{学科}/*.txt|*.md`）清洗归一为可入库的干净文本（`rag_data/corpus/{学科}/*.txt`），并定义统一标注规范。原始资料包括：人教版统编版教材、课标、高考真题、教辅、教师自有备课稿。

## 清洗规则（`scripts/clean_corpus.py`）

按序执行，每一条都记录统计：

1. **噪声行过滤**：去除纯页码、`第X页`、`--页码--`、页眉书名（如`人教版 必修 上册`）、`第X课/单元`等章节页眉、单字符空行。
2. **全角转半角**：全角空格/标点转半角（保留中文标点），统一排版。
3. **合并断行**：行尾无终止标点（。！？；：.…）且下一行非空时并入下一行，修复 PDF 复制的断行。
4. **公式归一**：`\frac{a}{b}` → `a/b`，多余空白压缩，保留可读性。
5. **去重**：按行前 60 字去重（保持顺序），消除重复段落。
6. **敏感/占位过滤**：检出 `{{var}}`、`TODO`、`FIXME`、`占位`、`待录入`、`此处插入` 等占位符并计数（不阻断，提示需人工补全）。

## 输出

- 清洗后文本：`rag_data/corpus/{学科}/{原始名}.txt`
- 清洗报告：`rag_data/logs/cleaning-report-{时间戳}.json`（含每文件 原始行→输出行、噪声/去重/敏感计数）
- 命令行支持 `--subject`（单科）、`--input`（自定义原始目录）、`--dry-run`（仅预览不写盘）

## 文件命名与标注规范

清洗后语料文件名作为元数据来源，约定：

```
{模块}_{章节}_{知识点}_{年级}.txt
```

`pipeline._parse_corpus_meta` 据此解析出 `module / chapter / section / grade`，其余字段（difficulty、source、exam_type、level 等）在知识树叶子节点中标注。

## 标注规范（知识树叶子节点）

每条知识点须携带（见 `schema.KnowledgeNode`）：

| 字段 | 说明 | 取值示例 |
|---|---|---|
| `kp_id` | 全局唯一编码 | `YW-M2C1S1-KP17` |
| `level` | 层级 1~5 | 5（知识点） |
| `grade` | 年级/学段 | `高一`/`必修一` |
| `difficulty` | 难度 1~5 | 3 |
| `importance` | 重要度 1~5 | 4 |
| `level_requirement` | 课标层次 | `了解/理解/掌握/应用` |
| `exam_type` | 关联高考题型 | `选择题`/`解答题`/`文言文阅读` |
| `source` | 来源 | `人教版统编版必修上册` |
| `version` | 课标/考纲版本 | `普通高中课程标准（2017年版2020年修订）` |

## 质量卡点

- 清洗必须**可审计**：每次清洗产出报告，可追溯每条文本的变换。
- 语料**不入库**：`raw/` 仅作原始存档，入库一律用 `corpus/` 清洗后文本。
- 敏感/占位计数大于 0 时，应在发布前人工核对补全。
- 学科命名统一用九科规范名：语文/数学/英语/物理/化学/生物/历史/地理/思想政治。

## 用法

```bat
:: 全科清洗
python scripts\clean_corpus.py
:: 单科预览（不写盘）
python scripts\clean_corpus.py --subject 数学 --dry-run
```
