# data - Student Business Data

This directory stores business data generated by the student app (history records, diagnosis data, homework data, etc.), corresponding to each function page in the main interface. Data is saved in JSON format.

## Directory Structure

| Folder | Module | Content |
|--------|--------|---------|
| `knowledge/` | Knowledge Teaching | Chat history (`history.json`) |
| `qa/` | Q&A | Q&A history (`history.json`) |
| `grading/` | Grading | Grading history (`history.json`) |
| `homework/` | Homework | Homework list and submissions (`homework.json`) |
| `practice/` | Practice | Practice history (`history.json`) |
| `diagnosis/` | Diagnosis | Scores, wrong answers, AI reports (`diagnosis.json`) |

## Notes

- Data files use JSON format, loaded into memory on startup, written to disk asynchronously on changes.
- Each module's history and diagnosis data are saved in their respective folders for easy backup and migration.
