# 孔孟·智学云 —— 学生端 ↔ 云端 ↔ 教师端 数据同步原型

基于 `rapid-prototype-craft` 高保真交互原型技能构建的纯静态原型，演示**学生端与教师端通过云端数据同步与互动**的完整链路。所有数据为 mock，通过 stub API 模拟经 `cloud` 目录流转，无需后端即可离线双击打开。

---

## 一、核心能力

| 链路 | 方向 | 说明 |
|---|---|---|
| 作业下发与接收 | 教师端 → 云端 → 学生端 | 教师创建并下发作业，学生端同步接收、在线提交 |
| 成绩公布与学情 | 教师端 → 云端 → 学生端 | 教师发布成绩，学生端查看成绩、排名与学情报告 |
| 学生提问/反馈 | 学生端 → 云端 → 教师端 → 学生端 | 学生发问，教师回复，学生查看回复 |
| 批改/讲解同步 | 教师端 → 云端 → 学生端 | 教师发布批改与讲解，学生端查看并标记已读 |

**班级/科目维度（关键设计）**：所有云端数据均带 `classId + subject` 维度。教师端采用三视图区分信息权限：

1. **我的任教现状**（可写）：仅统计任教班级 × 任教科目的数据，可下发作业、发布成绩、回复提问、批改作业。
2. **对应单科情况**（只读）：全校某科目跨所有班级的统计，供任课教师了解本学科全局。
3. **全年段全科情况**（只读）：全校各科各班数据分桶概览，供教务/年级视角查看。

学生端按「本班 + 本人选科」过滤，只看到与自己相关的数据。

## 三、本地运行

纯静态、零依赖。直接双击 `index.html` 即可在浏览器中打开，无需任何服务器或构建步骤。

## 四、推荐演示路径

1. **作业链路**：进入教师端「作业下发」→ 创建并下发作业 → 进入云端中心查看分桶与流转记录 → 进入学生端「作业中心」→ 同步接收 → 提交作业。
2. **成绩链路**：教师端「成绩学情」发布成绩 → 云端 → 学生端「成绩学情」查看成绩与学情。
3. **提问链路**：学生端「提问反馈」发问 → 云端 → 教师端「提问处理」回复 → 学生端查看回复。
4. **批改链路**：教师端「题目批改」发布批改 → 云端 → 学生端「批改讲解」查看并标记已读。

> 教师端切换「我的任教现状 / 对应单科情况 / 全年段全科情况」可直观看到班级·科目信息权限差异。

## 五、技术说明

- **技术栈**：纯 HTML + CSS + 原生 JS，`vanilla / pure-static`，离线可用。
- **设计契约**：`assets/components.js` 中冻结 App Shell + 导航，所有页面共用同一套外壳，仅填充 main-content，杜绝导航漂移。
- **数据源**：`assets/mock.js` 为唯一数据源，所有业务对象带 `classId`/`subject` 维度。
- **API 层**：`assets/api.js` 为 stub，每个函数标注了 `// TODO: replace with ...` 及对应真实接口（教师端 FastAPI `http://127.0.0.1:8767`），后续接入真实后端时仅需替换该层实现，签名保持不变。
- **模拟同步**：每次跨端操作通过 `pushSyncEvent` 写入一条同步事件，云端中心时间线即由此驱动，直观呈现「数据经 cloud 流转」。

## 六、后续接入真实后端

本原型为高保真静态交互演示，未连接真实后端。接入时：

1. 按 `assets/api.js` 中标注的接口契约实现教师端 FastAPI 服务。
2. 学生端可改为直读本地 `cloud` 目录 JSON（Electron 场景）。
3. 将 `api.js` 的 stub 逐一切换为真实 `fetch` 调用，保持函数签名与返回结构不变即可无缝替换。
