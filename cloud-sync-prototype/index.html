推荐演示路径：体验四大跨端同步链路

  1. 作业下发与接收：教师端「作业下发」创建并下发作业 → 云端分桶 → 学生端「作业中心」同步接收并提交。
  2. 成绩公布与学情：教师端「成绩学情」发布成绩 → 云端 → 学生端「成绩学情」查看成绩与学情报告。
  3. 学生提问/反馈：学生端「提问反馈」发送问题 → 云端 → 教师端「提问处理」回复 → 云端 → 学生端查看回复。
  4. 批改/讲解同步：教师端「题目批改」发布批改与讲解 → 云端 → 学生端「批改讲解」查看并标记已读。
